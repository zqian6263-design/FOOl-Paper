# Deep Residual Learning for Image Recognition

**作者**: Kaiming He et al. (Microsoft Research) | **年份**: 2016 | **会议**: CVPR 2016 Best Paper | **引用**: 170,000+

`computer-vision` `residual-learning` `image-classification` `deep-learning`

## 摘要

深度神经网络越深越难训练。我们提出残差学习框架：不直接学习目标映射 H(x)，而是学习残差 F(x) = H(x) − x。Shortcut connection（恒等跳跃连接）让网络层可以轻松传递恒等映射，深度增加不再带来退化。152 层 ResNet 在 ImageNet 上夺冠，比 VGG 深 8 倍但复杂度更低。残差学习原理极其通用，已成为几乎所有现代深度视觉架构的基础组件。

## 费曼拆解

### 一句话总结
让网络不学"我从零画什么"，而是学"我需要在上一层的基础上改什么"——就像修改草稿而不是重画。

### 术语降级表

| 术语 | 通俗解释 |
|------|---------|
| Residual (残差) | 目标输出减去输入：只学"差多少" |
| Shortcut connection | 一条"高速公路"从输入直达输出，跳过中间层 |
| Identity mapping | 什么也不做，原封不动传下去 |
| Degradation | 网络越深反而越差——不是过拟合，是优化困难 |
| Bottleneck block | 用 1×1 卷积先压缩再解压，省计算 |

### 从头推导

1. 直觉：如果新增的层什么也不做（恒等映射），深层网络至少不应比浅层差
2. 所以问题不是"深度有害"，而是**深层学不到恒等映射**
3. 解法：不要求网络直接学习 H(x)，而学习 F(x) = H(x) − x
4. Shortcut connection 实现 H(x) = F(x) + x
5. 当最优解接近恒等映射时，网络只需将 F(x) 推向 0 —— 比推向 H(x) 容易得多
6. 梯度通过 shortcut 直接反向传播，解决深层梯度消失

### 反事实

如果没有 ResNet，整个深度学习视觉领域可能停滞在 20 层左右。ResNet 的出现直接催生了 ImageNet 冠军从 22 层 (GoogLeNet) 跳跃到 152 层。更重要的是，残差连接被 Transformer (2017) 吸收为 Layer Normalization + Residual，间接成就了 GPT。可以说 ResNet 的 shortcut 是现代 AI 的"脊柱"。

## 第一性原理分析

### 追问链

| 追问 | 回答 |
|------|------|
| 为什么越深越差？ | 不是过拟合（训练误差也在上升）——是优化困难 |
| 优化为什么困难？ | SGD 在高维空间中找到"什么都不做"的解比"做点什么"的解更难 |
| 为什么残差学习解决这个问题？ | 将恒等映射作为默认行为——网络不需要主动学习它 |
| 有更简单的方案吗？ | Highway Networks（门控）也尝试解决，但多了门控参数，不如恒等 shortcut 简洁 |
| 恒等映射为什么如此重要？ | 它为梯度和信息提供了"无损通道"，保证至少不退化 |

### 假设审计

| 假设 | 评估 | 依据 |
|------|------|------|
| 恒等 shortcut 无损信息传递 | ✅ 验证 | 152 层能训练，梯度不消失 |
| 残差映射比原始映射更易优化 | ✅ 验证 | 浅层和深层 ResNet 训练曲线类似 |
| 维度不匹配用 1×1 卷积投影 | ✅ 合理 | 1×1 卷积是标准做法 |

## 公式解释

### 核心公式：y = F(x, {Wᵢ}) + x

| 符号 | 含义 | 维度 |
|------|------|------|
| x | 输入特征图 | H×W×C |
| F(x, {Wᵢ}) | 残差函数（通常是两三层卷积+BN+ReLU） | H×W×C |
| y | 输出特征图 | H×W×C |
| + | **逐元素加法**（关键：要求维度匹配） | — |

**结构分析**：这是一个等式——输出 = 残差路径 + 恒等路径。加法操作是 ResNet 的精髓。如果输入输出维度不匹配（如 stride=2 下采样），shortcut 上插入 1×1 卷积做线性投影：y = F(x) + W_s·x。

**类比**：想象你在导航——传统网络让你从零计算终点位置，ResNet 让你只需计算"离上一时刻偏了多少"，把绝大部分位置信息通过 shortcut 直接传下去。

## 创新与不足

### 创新点

- **类型**：真创新 — 首次提出残差学习框架解决深层网络的退化问题
- **核心贡献**：不是提出"更好的优化器"，而是**重新定义学习目标**——从学 H(x) 变成学 F(x)=H(x)−x
- **本质区别**：Highway Networks 用门控学习"传递多少"；ResNet 用纯恒等映射——更简单、参数更少、效果更好

### 不足

| 类别 | 具体问题 |
|------|---------|
| 为什么 rank 这么低的残差就够了？ | 论文没有解释残差函数的本质秩——后来 LoRA 论文才从低秩角度给出了一种解释 |
| Pre-activation 版本 | 原始 ResNet 是 post-activation，后来发现 pre-activation (BN→ReLU→Conv) 更好 |
| 宽度 vs 深度 | 论文聚焦深度，对宽度（Wide ResNet）的探索在后续工作中完成 |

### 改进方向

1. **[已实现]** Pre-activation ResNet：将 BN+ReLU 移到卷积前，信息流更通畅
2. **[已实现]** Wide ResNet：增加宽度比加深更有效
3. **[探索]** ResNet 与 LoRA 的深层联系：残差连接本质是"不做全量更新，只做低秩修正"——与 LoRA 的 ΔW = BA 异曲同工

## 我的思考

1. ResNet 的 shortcut 连接与 LoRA 的 BA 矩阵更新有结构上的同源性——两者都在说同一件事：高维空间的更新不需要高维表示。ResNet 让"残差"在特征空间流动，LoRA 让"残差"在参数空间流动。这可能不是巧合。

2. 一个容易被忽视的点：ResNet 的影响力远超视觉领域。Transformer 的 "Add & Norm" 就是残差连接 + LayerNorm，而 Transformer 又催生了 GPT。可以说 ResNet 的 shortcut 是现代 AI 基础设施的"DNA 片段"。

3. 论文最优雅的设计是"问题定义"——作者没有问"如何让深层网络更好优化？"，而是问"为什么深层网络连恒等映射都学不会？"这个问题的重新定义直接导向了 shortcut 的解决方案。这是研究方法的教科书级案例。

4. 与 Neural Causal Abstractions 的类比：残差连接相当于在模型内部建立了一条"因果不变通道"——无论中间层怎么变，输入信息有一条无损路径到达输出。这很像 Pearl 因果图中的后门调整：控制住某些路径，让因果效应通过其他路径传递。

5. 如果今天重新发明 ResNet，用 ViT/LoRA 时代的视角，可能不会把 shortcut 放在特征空间，而是放在注意力权重空间——这恰好就是 LoRA 的思路。

# 翻译 + 术语解释提示词

请将以下学术论文文本翻译为中文。

## 翻译原则

1. **准确性优先** — 技术术语保持原文中英文对照，如"attention mechanism（注意力机制）"
2. **术语首次出现时给出解释** — [术语]（[英文]）：[一句话解释]
3. **长难句拆分** — 英文的长定语从句拆为短句
4. **保留结构** — 保持原文的章节编号、公式编号、引用格式
5. **图表标题** — 翻译图表标题，保留原文对照
6. **引用保持原名** — 引用其他人名和论文标题不翻译

## 输出格式

```
### 📝 翻译

#### 原文对照（重要段落）

> **原文**: ...
> **译文**: ...

#### 术语解释

| 术语 | 解释 |
|------|------|
| {term} | {一句话解释} |
```

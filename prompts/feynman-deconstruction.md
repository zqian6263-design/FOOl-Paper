# 费曼拆解提示词

你正在用费曼技巧拆解一篇学术论文。费曼技巧的核心原则是：
**"如果你不能简单地解释它，说明你还没有真正理解它。"**

请遵循以下步骤：

## Step 1: 一句话总结
用一句话（不超过 50 字）告诉读者这篇论文到底在做什么。

## Step 2: 用最简单的话解释核心方法
假设你的听众是一位聪明但非本专业的本科生。
- 不要使用专业术语，或者使用时立即解释
- 用日常生活中的类比
- 解释"为什么这样做"而不是只描述"做了什么"

## Step 3: 指出难点
诚实标明哪些地方可能还没讲清楚：
- "这里可能有点绕，因为…"
- "如果你对 XX 不熟悉，可能觉得…"
- 给出深入理解这些难点的学习路径

## Step 4: 类比和实例
找一个生活中的例子来解释论文的核心思想。
例如：
- Transformer 的注意力机制 → "在图书馆找书时，注意力机制就像你只关注书架上和主题相关的几本书"
- 反向传播 → "就像玩'温度高低'猜谜游戏，每次猜测后根据提示调整方向"

## Step 5: 论证链条重构
用自己的逻辑重新组织论文的论证链条：
1. 问题 → 2. 已有方法的局限 → 3. 核心洞察 → 4. 方法设计 → 5. 实验验证 → 6. 结论

论文原文的章节顺序可能和逻辑链条不一致，你需要重构。

## 输出格式

```markdown
### 🧠 费曼拆解

#### 一句话总结
...

#### 最简单的解释
...

#### 难点提示
...

#### 生活类比
...

#### 论证链条
1. **问题**：...
2. **已有方法的问题**：...
3. **核心洞察**：...
4. **方法**：...
5. **验证**：...
6. **结论**：...
```
